# 📜 Code of Conduct – Global Dream Project (GDP Coin)

GDP Coin is an open‑source experiment under the **Apache‑2.0 License**.  
We want a community that is transparent, respectful, and focused on learning and building together.

---

## 🌍 Principles
- **Respect first** → No harassment, hate speech, or personal attacks.  
- **Learn together** → Share knowledge openly; GDP is a sandbox for experimentation.  
- **Hack, don’t harm** → Explore responsibly; no malicious code or exploits.  
- **Transparency** → Be clear when reporting bugs or suggesting features.  
- **Collaboration** → Fork, patch, and PR with constructive intent.  

---

## 🛡️ Moderation Rules
- Any **malicious code** or **exploit attempts** in PRs/issues will be removed.  
- Repeat offenders may be **banned temporarily or permanently**.  
- Security reports must follow responsible disclosure practices.  

---

## 🧩 Contribution Guidelines
- Keep commits clean and descriptive.  
- Respect repo structure — don’t dump random files.  
- Use placeholders for sensitive values (e.g., `0xYourWalletAddressHere`).  
- Never commit `.env` files, private keys, or secrets.  

---

## 🚀 Community Flow
1. Fork → Patch → Pull Request.  
2. Discuss ideas in Issues respectfully.  
3. Report vulnerabilities responsibly.  
4. Earn recognition through valid contributions.  

---

## 🧠 Enforcement
- Maintainers have final say on moderation.  
- Violations = warning → temporary ban → permanent ban if repeated.  
- Valid bug reporters may earn recognition in the GDP community.  

---

## 📧 Contact
For moderation or conduct concerns:  
**Open an Issue** in the repo or contact the maintainers directly.  

---

By contributing, you agree to follow this Code of Conduct and respect the **Apache‑2.0 License**.
