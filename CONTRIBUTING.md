# Contributing to GDP Coin (Global Dream Project)

We welcome contributions to **GDP Coin**, an experimental ERC‑20 token project under the **Apache‑2.0 License**.  
This project is about learning, community, and open collaboration.

## How to Contribute
- **Fork the repo** and create your branch from `main`.
- **Make changes** in `contracts/`, `scripts/`, or docs (`README.md`, etc.).
- **Test locally** using Hardhat before submitting.
- **Commit clearly** with descriptive messages.
- **Open a Pull Request** with details of your changes.

## Guidelines
- Use **placeholders** for private keys and sensitive values (`0xYourWalletAddressHere`, `.env`).
- Follow **best practices** for Solidity and TypeScript.
- Keep contributions aligned with the **Global Dream Project vision**: learning, experimentation, and community.
- Respect the **Apache‑2.0 License** — contributions must remain open‑source.

## Privacy & Security
- Never commit `.env` files, private keys, or secrets.
- Use `.gitignore` to exclude sensitive files.
- Report any security concerns responsibly via Issues.

## Code of Conduct
We aim to foster a welcoming and inclusive environment.  
Be respectful, constructive, and collaborative in discussions and contributions.
