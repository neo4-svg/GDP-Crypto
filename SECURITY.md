# 🔒 Security Policy – Global Dream Project (GDP Coin)

GDP Coin is an experimental ERC‑20 token project under the **Apache‑2.0 License**.  
We take security seriously and encourage responsible disclosure of vulnerabilities.

---

## 🛡️ Supported Versions
We currently support the **main branch** of this repository.  
Older forks or modified versions may not receive security updates.

---

## 🧩 Reporting a Vulnerability
- **Do not open public Issues** for security concerns.  
- Instead, report privately to the maintainers via email or direct contact.  
- Provide clear details:
  - Steps to reproduce
  - Potential impact
  - Suggested fix (if possible)

---

## 🚫 Prohibited Actions
- Do not exploit vulnerabilities on live deployments.  
- Do not publish private keys, `.env` files, or sensitive data in Issues or PRs.  
- Do not use GDP Coin for malicious activity — this project is for learning and experimentation only.

---

## ✅ Responsible Disclosure
We follow a **responsible disclosure model**:
1. Report privately.  
2. Allow maintainers time to investigate and patch.  
3. Public disclosure only after a fix is released.  

---

## 📜 License & Compliance
All contributions and disclosures are covered under the **Apache‑2.0 License**.  
By reporting, you agree to keep vulnerabilities private until resolved.

---

## 📧 Contact
For security concerns, please reach out to the maintainers directly.
